# homebase logo kit

- `symbol.svg`: full-colour mark for dark backgrounds. `symbol-on-light.svg`: for light backgrounds.
- `symbol-black.svg`, `symbol-white.svg`, `symbol-mono-*.svg`: one-colour versions.
- `symbol-small.svg` and `favicon.svg`: simplified cut for 16–32 px. Use it below 48 px instead of shrinking the full mark.
- `app-icon.svg`: rounded tile (22% radius). `lockup-horizontal-*.svg/png`: symbol + wordmark.
- `web/`: favicon.ico (16/32/48), favicon PNGs, apple-touch-icon (180, full-bleed), icon-192/512, maskable-512, site.webmanifest and head-snippet.html.

**Clear space:** keep at least ¼ of the symbol's height free on all sides.
**Minimum size:** full symbol 48 px; below that use the small cut. Lockup 120 px wide.
**Don't:** recolour outside the palette, stretch, add effects or shadows, or re-typeset the wordmark (it's outlined Inter, SIL OFL).
Not trademark-cleared.
